## 0.1.0 - 2026-06-11

### Added

- Local FastAPI and HTMX web app for progressive coding lessons.
- Seed course catalog for Python, Git, Bash, WebDev, k1s and WorkerBee, Roblox,
  Unity, and Unreal tracks.
- Local runtime execution for Python, Bash, Git, Node, and text-answer lessons.
- Local progress, badges, backup, and restore workflows.
- Codex CLI integration for lesson explanations and generated course drafts.
- WorkerBee validation and deployment manifests.
- `padawan.training-data.v1` course format with metadata, examples, exercises,
  and share-ready fields.
- Built-in user docs, newcomer install guide, and README demo media.
- One-line release installer and multiplatform wheelhouse release tooling.
